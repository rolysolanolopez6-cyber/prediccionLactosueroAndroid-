Acerca del modelo

El modelo se seleccionó comparando regresión lineal y bosque aleatorio mediante MAPE de validación en una partición cronológica. Para el uso en la app, el modelo seleccionado se reentrenó con el primer 80% de los registros; el 20% final se conserva para la evaluación reportada.
